# US 1: Mise en place d'un environnement sécurisé

Logiciel installé : `UTM` ou `VirtualBox`

Téléchargement de l'ISO windows 11 

Mise en place d'une machine virtuelle avec les paramètres suivants :
- 8 Go de RAM
- 4 CPU
- 64 Go de stockage
- réseau : Host only (pour éviter une fuite réseau non controlée)


## Conclusion

L'environnement sécurisé est prêt pour l'installation et l'exécution du malware
